# 서윤의 오늘 — 개인 하루 계획 PWA

기존 `today-planner` 프로젝트를 확장한 개인용 하루 관리 앱입니다. iPhone Safari에서 **공유 → 홈 화면에 추가**로 설치해 사용하는 것을 최우선으로 설계했습니다.

## 핵심 구성

- 오늘: 진행률, 핵심 목표 최대 3개, 날짜별 할 일, 오늘 루틴, 집중 타이머, 빠른 메모, 하루 마무리, 내일 준비
- 캘린더: 월간 보기, 과거/미래 날짜별 할 일 확인 및 작성
- 루틴: 매일/요일 반복, 오늘 체크, 이번 주 진행률
- 기록: 이번 주 간단 요약, 날짜별 기분/완료 수/한 줄 기록/집중 기록
- 프로필/설정: 여서윤 개인화, 시스템/라이트/다크 테마, JSON 백업/복원

## 기존 데이터 보존

기존 버전과 동일한 `localStorage` 키인 `todayPlannerData`를 계속 사용합니다. 앱 실행 시 기존 v1 데이터의 날짜별 할 일, 완료 상태, 중요 표시, 순서, 메모, 기분을 읽어 v2 구조로 자동 정리합니다.

기존 `memo` 문자열은 v2에서 빠른 메모 1개로 변환됩니다. 마이그레이션 시 원본 JSON은 가능한 경우 `todayPlannerDataBackupV1` 키에도 한 번 백업합니다.

## 실행 방법

Service Worker 때문에 `index.html`을 `file://`로 직접 열지 말고 HTTP 서버에서 실행하세요.

가장 쉬운 방법:

1. 이 폴더를 VS Code로 엽니다.
2. Live Server 확장을 사용해 `index.html`을 실행합니다.
3. 브라우저 콘솔에서 오류가 없는지 확인합니다.

또는 터미널에서 Python이 있다면:

```bash
python -m http.server 8080
```

그 뒤 `http://localhost:8080`에서 확인할 수 있습니다.

## GitHub Pages / iPhone 설치

1. 이 폴더의 파일을 GitHub 저장소에 올립니다.
2. GitHub Pages를 활성화해 HTTPS 주소로 배포합니다.
3. iPhone Safari에서 해당 주소를 엽니다.
4. 공유 버튼 → **홈 화면에 추가**를 누릅니다.
5. 홈 화면의 `오늘` 아이콘으로 실행합니다.

## 데이터 저장

서버나 로그인 없이 브라우저 `localStorage`에 저장됩니다. 다음 데이터가 유지됩니다.

- 날짜별 할 일/완료/중요/순서/핵심 목표
- 미래 날짜 계획
- 루틴과 요일 반복/날짜별 완료 기록
- 빠른 메모
- 기분과 한 줄 기록
- 집중 타이머 상태와 완료 세션
- 프로필과 테마 설정

설정의 **데이터 백업 내보내기**를 사용하면 JSON 파일로 수동 백업할 수 있습니다. 브라우저 사이트 데이터 자체를 삭제하면 로컬 데이터도 함께 삭제될 수 있습니다.

## PWA / 캐시

- `display: standalone`
- 상대 경로 기반 `start_url` / `scope`
- iPhone safe-area 대응
- 기본 앱 셸 오프라인 캐시
- Service Worker 캐시 버전 `today-planner-v5.0.0`
- 온라인일 때 네트워크 파일을 우선 사용하고 실패할 때 캐시로 폴백하여 오래된 CSS/JS가 계속 남는 문제를 줄였습니다.


## v3 프로필 사진
- 오른쪽 위 프로필 버튼을 누른 뒤 **프로필 사진 → 사진 보관함에서 선택**을 사용하세요.
- iPhone에서는 시스템 사진 선택 UI가 열리며 사진 보관함의 이미지를 고를 수 있습니다.
- 선택한 이미지는 브라우저에서 가운데 정사각형으로 크롭한 뒤 320×320 JPEG로 압축해 앱 데이터에 저장합니다.
- 선택한 사진은 상단 프로필 버튼과 프로필/설정 화면에 함께 표시됩니다.
- **사진 삭제 · 기본 아바타로 되돌리기**로 기본 이니셜 아바타로 언제든 복원할 수 있습니다.
- 프로필 사진은 데이터 백업 JSON에도 포함되므로 같은 앱 데이터로 가져오면 함께 복원됩니다.
